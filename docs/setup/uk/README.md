# Підключіть EngrAmo до свого ШІ-асистента

**Інші мови:** [English](../en/README.md) · [Español](../es/README.md) · [Русский](../ru/README.md)

Після підключення ви можете звичайними словами просити ШІ-асистента створювати колоди карток, додавати
картки, шукати їх або планувати навчання. Усе, що він створює, зберігається у вашому акаунті EngrAmo й
одразу доступне для навчання на <https://study.engramo.app>.

**Перед початком:** потрібен акаунт EngrAmo. Якщо його ще немає, створіть його на
<https://study.engramo.app>. На сторінці входу, яку ви побачите під час налаштування, кнопки реєстрації немає.

## Оберіть застосунок

### У браузері: нічого не потрібно встановлювати

| Застосунок | Інструкція | Аудіо в картках |
|---|---|---|
| Claude (claude.ai, а також Claude Desktop і мобільний застосунок) | [Claude](claude.md) | Ні |
| ChatGPT (chatgpt.com) | [ChatGPT](chatgpt.md) | Ні |
| Gemini (gemini.google.com) | [Gemini](gemini.md) | Ні |

Це займає близько 2 хвилин. Ви входите зі своєю поштою та паролем EngrAmo; нічого копіювати чи вставляти не треба.

### На комп'ютері, з аудіо в картках

Хочете, щоб ШІ додавав до карток озвучення (наприклад, природний англійський голос читає кожну фразу)?
Аудіо працює лише із застосунком, встановленим на вашому комп'ютері, і з вашим власним безкоштовним
ключем Google.

| Застосунок | Інструкція |
|---|---|
| Claude Desktop | [Claude Desktop з аудіо](claude-desktop-audio.md) |
| Antigravity | [Antigravity з аудіо](antigravity-audio.md) |

Для обох спершу потрібні два ключі. Як їх отримати, описано в [Отримайте ключі](keys.md) (близько 5 хвилин).

## Після налаштування

Спробуйте одне з цього в новому чаті:

```text
Покажи мої каталоги EngrAmo.
```

```text
Створи каталог EngrAmo «Англійська для подорожей» з 10 картками корисних фраз для готелю й ресторану.
На лицьовому боці — фраза англійською, на звороті — переклад українською.
```

Більше готових запитів (англійською): [приклади запитів](../../prompt-examples.md).

## Як припинити використання EngrAmo в застосунку

Відкрийте застосунок EngrAmo, перейдіть у **Settings → Connected apps** (Налаштування → Підключені
застосунки) і скасуйте доступ для цього застосунку. Також можна видалити підключення в самому
ШІ-застосунку (у кожній інструкції вказано, де саме).
