# Claude Desktop з аудіо в картках

[← Усі інструкції](README.md)

Встановіть розширення EngrAmo в Claude Desktop, щоб Claude міг створювати картки **й додавати до них
озвучення**. Не треба встановлювати інші програми чи редагувати файли. Працює на Mac, Windows і Linux,
зокрема на безкоштовному тарифі Claude. Займає близько 5 хвилин.

## Що потрібно

- Застосунок Claude Desktop: завантажте на <https://claude.ai/download>
- Ваш **API-токен EngrAmo** і **API-ключ Gemini**: [отримайте ключі](keys.md)

## Кроки

1. Завантажте файл розширення: [engramo.mcpb](https://github.com/engramo-developer/engramo-mcp/releases/latest/download/engramo.mcpb).
2. Відкрийте Claude Desktop.
3. Двічі клацніть завантажений файл `engramo.mcpb` (або перетягніть його у вікно Claude Desktop).
4. Натисніть **Install** (Встановити).

   Claude покаже червоне попередження: розширення отримає доступ до вашого комп'ютера, а розробника не
   перевірено компанією Anthropic. Claude показує його для всіх розширень, встановлених із файлу.
   Натисніть **Install**, щоб продовжити.
5. Заповніть два поля:
   - **EngrAmo API token:** вставте свій токен EngrAmo.
   - **Gemini API keys for card audio:** вставте свій ключ Gemini. (Кілька ключів? Розділіть їх комами.)
6. Натисніть **Save** (Зберегти) і переконайтеся, що розширення **увімкнено**.

Claude зберігає обидва ключі в захищеному сховищі вашого комп'ютера (Keychain на Mac).

## Перевірте, що все працює

Відкрийте новий **Chat** (розширення не працює в режимі Code у Claude) і вставте:

```text
Перевір моє підключення до EngrAmo: виклич get_server_version, list_tts_voices і get_subscription_usage.
Простими словами скажи версію сервера, чи готове аудіо (і який голос за замовчуванням), мій тариф і
скільки карток я ще можу створити. Якщо якийсь виклик не вдався, поясни чому і як це виправити.
```

Коли Claude попросить дозвіл на використання EngrAmo, натисніть **Allow** (Дозволити). Він має сказати,
що аудіо готове.

Потім спробуйте:

```text
Створи каталог EngrAmo «Англійська для співбесіди» з 10 картками корисних фраз. На лицьовому боці —
фраза англійською, на звороті — переклад українською та приклад. Додай аудіо до кожної картки.
```

## Корисно знати

- **Уже підключили EngrAmo в Claude у браузері?** У того підключення немає аудіо. Коли потрібне аудіо,
  починайте повідомлення з «Через розширення EngrAmo…» або вимкніть веб-конектор у Claude Desktop у
  **Settings → Connectors**.
- **Змінити ключі пізніше:** **Settings → Extensions → EngrAmo → Configure** (Налаштувати).
- **Оновлення:** розширення не оновлюється саме. Щоб оновити, знову завантажте `engramo.mcpb` і
  встановіть так само.
- **Аудіо** створюється для лицьового боку кожної картки, до 20 карток за раз. Більші колоди Claude сам
  розбиває на частини.

## Якщо щось не так

| Проблема | Що робити |
|---|---|
| Claude каже, що аудіо недоступне | Перевірте ключ Gemini в **Settings → Extensions → EngrAmo → Configure**, потім повністю закрийте Claude Desktop (⌘Q на Mac) і відкрийте знову. |
| «Invalid token» або EngrAmo не відповідає | Згенеруйте новий токен EngrAmo ([ключі](keys.md)) і вставте його в **Configure**. |
| Аудіо зупиняється з повідомленням про квоту чи «rate limit» | Безкоштовну денну квоту Gemini вичерпано. Спробуйте завтра або додайте ще один ключ ([ключі](keys.md)). |
