# Получите ключи (для аудио)

[← Все инструкции](README.md)

Для настроек с аудио ([Claude Desktop](claude-desktop-audio.md), [Antigravity](antigravity-audio.md))
нужны два ключа. Ключ — это длинный текст, похожий на пароль, который позволяет приложению действовать от
вашего имени. Занимает около 5 минут.

> **Держите ключи в секрете.** Не вставляйте их в чат, письмо или на скриншот. Любой, у кого есть ключ,
> может пользоваться вашим аккаунтом. Если ключ попал в чужие руки, удалите его и создайте новый.

## 1. API-токен EngrAmo

Позволяет приложению на вашем компьютере пользоваться вашим аккаунтом EngrAmo.

1. Откройте <https://study.engramo.app> и войдите.
2. Нажмите **значок человека** (справа вверху) → **API token**.
3. Нажмите **Generate** (Сгенерировать).
4. Скопируйте токен (он начинается с `engramo_`) и сохраните в надёжном месте, например в менеджере
   паролей. Позже вы можете уже не увидеть его снова. Если потеряете, просто сгенерируйте новый.

## 2. API-ключ Gemini (бесплатно)

Позволяет приложению создавать озвучку карточек голосами Google. Это бесплатно, и аудио расходует вашу
собственную квоту Google, а не ваш тариф EngrAmo.

1. Откройте <https://aistudio.google.com/apikey> и войдите с аккаунтом Google.
2. Если попросит, примите условия.
3. Нажмите **Create API key** (Создать API-ключ). Если попросит выбрать проект, выберите любой (или
   разрешите создать новый).
4. Скопируйте ключ (обычно он начинается с `AIza`) и сохраните в надёжном месте.

**Планируете много аудио?** У бесплатной квоты есть дневной лимит. Можно создать ключи в нескольких
разных проектах Google и ввести их все через запятую (`ключ1,ключ2`). EngrAmo переключается на следующий
ключ, когда предыдущий исчерпан.
