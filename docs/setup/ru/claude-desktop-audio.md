# Claude Desktop с аудио в карточках

[← Все инструкции](README.md)

Установите расширение EngrAmo в Claude Desktop, чтобы Claude мог создавать карточки **и добавлять к ним
озвучку**. Не нужно устанавливать другие программы или редактировать файлы. Работает на Mac, Windows и
Linux, в том числе на бесплатном тарифе Claude. Занимает около 5 минут.

## Что нужно

- Приложение Claude Desktop: скачайте на <https://claude.ai/download>
- Ваш **API-токен EngrAmo** и **API-ключ Gemini**: [получите ключи](keys.md)

## Шаги

1. Скачайте файл расширения: [engramo.mcpb](https://github.com/engramo-developer/engramo-mcp/releases/latest/download/engramo.mcpb).
2. Откройте Claude Desktop.
3. Дважды щёлкните скачанный файл `engramo.mcpb` (или перетащите его в окно Claude Desktop).
4. Нажмите **Install** (Установить).

   Claude покажет красное предупреждение: расширение получит доступ к вашему компьютеру, а разработчик не
   проверен компанией Anthropic. Claude показывает его для всех расширений, установленных из файла.
   Нажмите **Install**, чтобы продолжить.
5. Заполните два поля:
   - **EngrAmo API token:** вставьте свой токен EngrAmo.
   - **Gemini API keys for card audio:** вставьте свой ключ Gemini. (Несколько ключей? Разделите их запятыми.)
6. Нажмите **Save** (Сохранить) и убедитесь, что расширение **включено**.

Claude хранит оба ключа в защищённом хранилище вашего компьютера (Keychain на Mac).

## Проверьте, что всё работает

Откройте новый **Chat** (расширение не работает в режиме Code в Claude) и вставьте:

```text
Проверь моё подключение к EngrAmo: вызови get_server_version, list_tts_voices и get_subscription_usage.
Простыми словами скажи версию сервера, готово ли аудио (и какой голос по умолчанию), мой тариф и
сколько карточек я ещё могу создать. Если какой-то вызов не удался, объясни почему и как это исправить.
```

Когда Claude попросит разрешение на использование EngrAmo, нажмите **Allow** (Разрешить). Он должен
сказать, что аудио готово.

Затем попробуйте:

```text
Создай каталог EngrAmo «Английский для собеседования» из 10 карточек с полезными фразами. На лицевой
стороне — фраза на английском, на обороте — перевод на русский и пример. Добавь аудио к каждой карточке.
```

## Полезно знать

- **Уже подключили EngrAmo в Claude в браузере?** У того подключения нет аудио. Когда нужно аудио,
  начинайте сообщение с «Через расширение EngrAmo…» или выключите веб-коннектор в Claude Desktop в
  **Settings → Connectors**.
- **Изменить ключи позже:** **Settings → Extensions → EngrAmo → Configure** (Настроить).
- **Обновления:** расширение не обновляется само. Чтобы обновить, снова скачайте `engramo.mcpb` и
  установите так же.
- **Аудио** создаётся для лицевой стороны каждой карточки, до 20 карточек за раз. Большие колоды Claude
  сам разбивает на части.

## Если что-то не так

| Проблема | Что делать |
|---|---|
| Claude говорит, что аудио недоступно | Проверьте ключ Gemini в **Settings → Extensions → EngrAmo → Configure**, затем полностью закройте Claude Desktop (⌘Q на Mac) и откройте снова. |
| «Invalid token» или EngrAmo не отвечает | Сгенерируйте новый токен EngrAmo ([ключи](keys.md)) и вставьте его в **Configure**. |
| Аудио останавливается с сообщением о квоте или «rate limit» | Бесплатная дневная квота Gemini исчерпана. Попробуйте завтра или добавьте ещё один ключ ([ключи](keys.md)). |
