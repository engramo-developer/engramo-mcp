# Подключите EngrAmo к своему ИИ-ассистенту

**Другие языки:** [English](../en/README.md) · [Español](../es/README.md) · [Українська](../uk/README.md)

После подключения можно обычными словами просить ИИ-ассистента создавать колоды карточек, добавлять
карточки, искать их или планировать обучение. Всё, что он создаёт, сохраняется в вашем аккаунте EngrAmo и
сразу доступно для изучения на <https://study.engramo.app>.

**Перед началом:** нужен аккаунт EngrAmo. Если его ещё нет, создайте его на <https://study.engramo.app>.
На странице входа, которую вы увидите при настройке, кнопки регистрации нет.

## Выберите приложение

### В браузере: ничего не нужно устанавливать

| Приложение | Инструкция | Аудио в карточках |
|---|---|---|
| Claude (claude.ai, а также Claude Desktop и мобильное приложение) | [Claude](claude.md) | Нет |
| ChatGPT (chatgpt.com) | [ChatGPT](chatgpt.md) | Нет |
| Gemini (gemini.google.com) | [Gemini](gemini.md) | Нет |

Это занимает около 2 минут. Вы входите со своей почтой и паролем EngrAmo; ничего копировать и вставлять не нужно.

### На компьютере, с аудио в карточках

Хотите, чтобы ИИ добавлял к карточкам озвучку (например, естественный английский голос читает каждую
фразу)? Аудио работает только с приложением, установленным на вашем компьютере, и с вашим собственным
бесплатным ключом Google.

| Приложение | Инструкция |
|---|---|
| Claude Desktop | [Claude Desktop с аудио](claude-desktop-audio.md) |
| Antigravity | [Antigravity с аудио](antigravity-audio.md) |

Для обоих сначала нужны два ключа. Как их получить, описано в [Получите ключи](keys.md) (около 5 минут).

## После настройки

Попробуйте одно из этого в новом чате:

```text
Покажи мои каталоги EngrAmo.
```

```text
Создай каталог EngrAmo «Английский для путешествий» из 10 карточек с полезными фразами для отеля и
ресторана. На лицевой стороне — фраза на английском, на обороте — перевод на русский.
```

Больше готовых запросов (на английском): [примеры запросов](../../prompt-examples.md).

## Как перестать использовать EngrAmo в приложении

Откройте приложение EngrAmo, перейдите в **Settings → Connected apps** (Настройки → Подключённые
приложения) и отзовите доступ для этого приложения. Также можно удалить подключение в самом
ИИ-приложении (в каждой инструкции указано, где именно).
